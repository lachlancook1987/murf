# Backtest — current entry rules vs swing alternatives (2026-09-29)

Data: Kraken public OHLC, 120 most liquid USD alt pairs (>$150k/24h), last 720 candles each
(1h ≈ 30d, 4h ≈ 120d, 1d ≈ 720d). Signal at bar close, entry next bar open +0.1% slip, trailing
stop checked bar-by-bar (stop before target, gap-aware), one position per pair. Fees: taker
0.8%/leg, maker 0.4%/leg (confirmed via `kraken.sh fees`; 30d volume $684, next tier at $2,500).
Code: `scripts/backtest/` (fetch_ohlc.py → ohlc.json, backtest.py, robustness.py).

| Test | n | Win | Avg net | PF |
|---|---|---|---|---|
| 1h current rules (mom>3%/5%, near 24h high, 2 up closes), 2.5% trail, taker | 322 | 17.7% | −1.75% | 0.31 |
| 1h current rules + T1 3% limit | 333 | 30.3% | −1.91% | 0.22 |
| 1h RANDOM entries, same exit (baseline) | 1359 | 24.8% | −1.18% | 0.40 |
| 1h current rules, zero fees | 322 | 31.7% | −0.15% | 0.89 |
| 4h breakout (20-bar high, vol>2x, >EMA50), 3xATR trail, 60 bars, maker-in/taker-out | 1032 | 35.6% | +0.12% | 1.03 |
| same, maker both sides | 1032 | 37.6% | +0.52% | 1.16 |
| same, taker both sides | 1032 | 34.5% | −0.28% | 0.93 |
| 4h random baseline (3xATR/60) | 1068 | 32.3% | −0.19% | 0.95 |
| 4h pullback-in-uptrend (RSI<42 near EMA20) | 662 | 33.2% | −0.45% | 0.89 |
| 1d breakout / pullback | 761 / 417 | 36% / 33% | −0.22% / −2.05% | 0.96 / 0.69 |

Findings: (1) current 1h chase rules reproduce the live record (~18–30% win, ≈−1.5%/trade) and are
WORSE than random entries; even at zero fees they are negative. (2) Swing on 4h with ATR trail is
roughly breakeven, +0.3pp better than random — SE ≈ 0.34%, so NOT statistically distinguishable
from zero. Halves split: first half −2.66%, second half +1.76% (regime dependent). (3) Fees are
decisive: maker vs taker swings the same strategy from −0.28% to +0.52%. (4) Pullback variant
tested negative — not adopted. Caveats: universe is today's liquid pairs (survivorship bias flatters
results; median alt +17% over 120d), long-only, single regime.
